Rive sur le site Novances

Démonstration du pipeline d'animation. Rien ici n'est en production.

1 · Rive tourne bien sur ton site

Exemple officiel Rive (chargé depuis le CDN Rive) — juste pour prouver que le runtime fonctionne ici. Tu peux interagir avec.

2 · L'emplacement de TON icône

En attente de _work/rive-demo/icons/entrepreneur.riv. Dès que tu y déposes ton export Rive, il s'anime ici. (En cas d'absence/erreur, on bascule sur l'icône actuelle — c'est le mécanisme de repli qu'on garde en prod.)

3 · Comment tu produis tes icônes

  1. Crée un compte sur rive.app → « New File ».
  2. Dessine l'icône (ou importe ton SVG actuel : File → Import), une seule encre navy, trait fin.
  3. Onglet Animate : crée tes animations (l'orbite qui tourne, la balance qui oscille…).
  4. Ajoute une State Machine avec un input hover (Boolean) pour le survol.
  5. Export → Runtime (.riv). Dépose le fichier dans _work/rive-demo/icons/.
  6. Dis-moi le nom de l'artboard et de la state machine : je règle l'intégration.
